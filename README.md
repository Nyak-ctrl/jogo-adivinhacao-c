# Jogo de Adivinhação em C

Um jogo de adivinhação desenvolvido em linguagem C, onde o objetivo do utilizador é descobrir um número secreto gerado aleatoriamente entre 1 e 100[cite: 1, 2]. O projeto conta com diferentes níveis de dificuldade e armazenamento do número secreto em ficheiro de texto[cite: 2].

---

## Funcionalidades

* **Níveis de Dificuldade:**
  * **Fácil:** Tentativas infinitas até acertar.
  * **Normal:** Limite de 10 tentativas.
  * **Difícil:** Limite de 3 tentativas.
* **Feedback Dinâmico:** O programa indica se o número secreto é maior ou menor do que o palpite dado;
* **Manipulação de Ficheiros:** O número secreto gerado aleatoriamente é gravado e lido diretamente de um ficheiro de texto (`numero.txt`).
